# 在小板上跑本地 LLM（Qwen2.5 + llama.cpp）

纯 CPU 推理，静态编译，板上无运行时依赖。Web 界面自包含（LuCI app + 免登录页面）。

| 目录 | 目标 | 内容 |
|---|---|---|
| [rk3566/](rk3566/) | RK3566 + OpenWrt 21.02（4×A55） | 交叉编译脚本、1.8GHz cpufreq 解锁补丁、LuCI app、聊天页面、i18n |

## 实测速度（Qwen2.5 Q4，-t 4）

| SoC | 内存 | 0.5B | 1.5B | 3B |
|---|---|---|---|---|
| RK3566 @1.8GHz | 4 GB | 8.0 t/s | 3.7 t/s | 1.8 t/s（Q4_0 2.4） |

经验：**4GB 板子的实用上限是 1.5B**；3B 峰值内存 3.4GB，KV 一涨就 OOM。
